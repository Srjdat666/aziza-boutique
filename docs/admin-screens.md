# لوحة الإدارة — قائمة الشاشات

تطبيق PWA mobile-first في [`apps/admin`](../apps/admin).

| # | المسار | الوصف | المرحلة |
|---|--------|--------|---------|
| 1 | `/login` | بريد + كلمة مرور (Supabase Auth)، TOTP 2FA للمالك | MVP |
| 2 | `/` | لوحة اليوم: طلبات جديدة، مخزون منخفض | MVP |
| 3 | `/products` | قائمة المنتجات + بحث + نشر/إخفاء | MVP |
| 4 | `/products/new` | إضافة منتج + variants + رفع صور | MVP |
| 5 | `/products/:id` | تعديل منتج | MVP |
| 6 | `/orders` | كل الطلبات + فلتر بالحالة | 2 |
| 7 | `/orders/:id` | تفاصيل، تغيير حالة، «إرسال تحديث واتساب»، طباعة تجهيز | 2 |
| 8 | `/inventory` | تنبيهات المقاسات المنخفضة | 2 |
| 9 | `/delivery-zones` | مدن ورسوم Mara | 2 |
| 10 | `/pos` | بيع محلي — خصم مخزون فوري | 3 |
| 11 | `/promo` | أكواد خصم | 3 |
| 12 | `/reports` | مبيعات يوم/شهر، الأكثر مبيعاً | 3 |
| 13 | `/customers` | قائمة زبونات + تصدير CSV للبث | 3 |
| 14 | `/team` | أدوار: owner، seller، fulfillment | 3 |
| 15 | `/help` | FAQ ودليل سريع (التدريب) | MVP |
